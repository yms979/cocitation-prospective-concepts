# Prospective technology concepts from predicted co-citation links

Data and code for the manuscript. The pipeline predicts co-citation links that do
not yet exist, inserts each predicted link into the citation network as a
*prospective node*, embeds that node with a text-initialised GAT, projects the
embedding into the ada-002 text space, and inverts it into a technology concept
with vec2text. The 55 generated concepts are screened by three LLM judges and
matched against patents published after the study period.

`python src/verify_reported_numbers.py` recomputes all of them offline.

## Layout

```
data/raw/        seed patents, cited patents, 120 subsequent patents (validation set)
data/networks/   co-citation and citation networks before / after prediction (large files gzipped)
data/            predicted links, projected embeddings, concepts, judge verdicts, similarities, baselines
tables/          Table 1, Table 2, Table B.1, Appendix B
src/             code by stage: 01 networks, 02 link prediction, 03 embedding,
                 04 cross-modal alignment, 05 concept generation, 06 evaluation, 07 CPC analysis
```

See `data/README.md` for the data dictionary and `src/README.md` for the scripts.

## Running

```bash
pip install torch==2.3.0 --index-url https://download.pytorch.org/whl/cu121
pip install torch-geometric==2.7.0 && pip install -r requirements.txt
cp .env.example .env            # OPENAI_API_KEY, ANTHROPIC_API_KEY, GOOGLE_API_KEY
set -a; source .env; set +a
scripts/unpack_data.sh          # decompress the network files
```

Scripts take no arguments and resolve paths relative to the repository root. Run
them in stage order. Stages 3 to 5 need a GPU (16 GB or more) and an OpenAI key;
stage 6 judges need OpenAI, Anthropic and Google keys. Link prediction and GAT
training are not seeded, so a fresh run differs slightly from the shipped files,
which are the run reported in the manuscript.

Full text-embedding and node-embedding matrices (200 to 300 MB each) and trained
projector weights are not included; they are regenerated by stages 3 and 4 or
available on request.
